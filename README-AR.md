# مشروع الصفحة المقصودة للشركة التقنية

مشروع React TypeScript مع Tailwind CSS يعرض صفحة مقصودة لشركة تسويق رقمي باللغة العربية.

## المميزات

- **React 19** مع TypeScript
- **Tailwind CSS** للتصميم
- **Vite** لأداء سريع
- **تصميم متجاوب** يتكيف مع جميع الأجهزة
- **دعم اللغة العربية** مع خط Cairo
- **تدرجات لونية جذابة**
- **أزرار تفاعلية**

## كيفية التشغيل

1. تثبيت المتطلبات:
```bash
npm install
```

2. تشغيل الخادم المحلي:
```bash
npm run dev
```

3. بناء المشروع للإنتاج:
```bash
npm run build
```

## البنية

```
src/
  components/
    HeroSection.tsx     # المكون الرئيسي للصفحة
  App.tsx              # المكون الجذر
  index.css            # ملف CSS الرئيسي مع Tailwind
  main.tsx             # نقطة دخول التطبيق
```
