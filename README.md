# Tech Company Landing Page Project

A React TypeScript project with Tailwind CSS showcasing a landing page for a digital marketing company in Arabic.

## Features

- **React 19** with TypeScript
- **Tailwind CSS** for styling
- **Vite** for fast performance
- **Responsive design** for all devices
- **Arabic language support** with Cairo font
- **Attractive color gradients**
- **Interactive buttons**

## How to Run

1. Install dependencies:
```bash
npm install
```

2. Start the local server:
```bash
npm run dev
```

3. Build the project for production:
```bash
npm run build
```

## Structure

```
src/
  components/
    HeroSection.tsx     # Main page component
  App.tsx              # Root component
  index.css            # Main CSS file with Tailwind
  main.tsx             # App entry point
```
